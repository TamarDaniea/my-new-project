# Shalom Platform Backend

This is the backend for the Shalom Platform, built with Node.js, Express, and MySQL.

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone [YOUR_REPO_URL]
    cd Shalom-Platform-Backend
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Set up environment variables:**
    Create a `.env` file in the root directory and add your database credentials and other configurations (see `.env.example` or documentation).
4.  **Run the server:**
    ```bash
    npm start
    # Or for development with hot-reloading:
    npm run dev
    ```
